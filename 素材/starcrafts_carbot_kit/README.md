## 引擎快速接入

1. **3D 用 GLB**：拖入工程，顶层节点名 = 资产 key（对照 `docs/assets_manifest.csv`）。
2. **2D 用 PNG**：`sheets/singles/<key>.png`，512×512 透明底，坐标已居中、3/4 斜前视角、带描边。
3. 渲染规格：Cycles 512² 透明底 + Freestyle 描边 2.6px（#1e2230）；色板 sRGB hex 见源工作区 `research/UNIT_LORE*.py`。

## 风格规范（Carbot 造型语言）

体积全圆润（球/蛋/胶囊）｜ 小短肢 ｜ 点眼/豆豆眼/面罩极简面部 ｜ 大色块平涂+深描边 ｜ 身份靠 1-2 个标志物（枪兵矩形枪、光刃、锯齿嘴）｜ 悬浮单位整体抬升（领主 2.05/巨像 2.35 等， builders 内置）。

## 来源与再生成

源项目工作区：`e:\godot\blender\starcrafts\`（构建脚本在 `scripts/`，301 张参考图与 79 份调研档案在 `refs/`、`research/`，全部过程渲染在 `renders/`）。修改流程：改 builder → 重跑（命令见 docs/交付文档.md）→ 验证 → 拷贝新产物到本包并升级版本号。三个批次（单位/建筑/英雄）均通过 visual-judge 多轮视觉终验。
