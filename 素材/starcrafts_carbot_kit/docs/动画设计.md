## 1. 动画风格原则（Carbot 动画语言）

对照 StarCrafts 动画与用户已定型的"过度烹饪"动画包（`anim_lib` 沿用其 NLA 管线），五条原则：

1. **果冻弹性**：所有运动带 squash & stretch——落地压扁 (sy 0.92)、起跳拉长，身体是果冻不是刚体；
2. **小短腿高频**：步频快、步幅小、抬脚夸张，" frantic scurry "是全系列基调；
3. **原地跑步机**：move 片段在原地播（世界位移交给引擎），标准游戏做法，片段天然无缝循环；
4. **呼吸常在**：idle 不是静止——2 起/循环的呼吸浮沉 + 3 帧眨眼（0.625 相位），活物感；
5. **整数倍循环**：所有正弦用整数倍 TAU，首尾帧严格相等，循环零跳变（引擎随便循环）。

**规格**：24 fps；idle 统一 48 帧（2s）；move 按原型 16-48 帧（见 §3 参数表）。

## 2. 运动原型分类（9 类）

不看单位身份、只看"它靠什么移动"——55 个活动资产（单位+英雄）归为 9 类原型，每类一个参数化片段工厂（建筑 24 栋只做 idle，见 §4）：

| 原型 | 工厂 | 运动特征 | 成员 |
|---|---|---|---|
| **biped 双足** | `clip_walk_biped` | 碎步/摇摆步/行军步三档 | marine, scv, reaper, marauder, ghost, zealot, 高阶/黑暗圣堂, 雷诺, 泰凯斯, 诺娃, 蒙斯克, 阿塔尼斯, 泽拉图, 阿拉纳克 |
| **quad 四足** | `clip_hop_quad` / `clip_stomp_quad` | 轻跳（小狗）/重踏（雷兽） | zergling, ultralisk, dehaka, zagara, queen, fenix |
| **roll 滚** | `clip_roll` | 连续自转+压扁弹跳 | baneling |
| **crawl 爬** | `clip_skitter` | 腹部蠕动+细腿乱蹬 | infestor, abathur, roach |
| **hover 悬浮** | `clip_hover` | 正弦浮沉+触须摆 | overlord, observer, probe, sentry |
| **fly 飞** | `clip_fly` | 浮沉+俯仰+翼扑扇 | mutalisk, corruptor, viper, phoenix, void_ray |
| **tank 载具** | `clip_tank` | 低频颠簸+Rock+炮管点头 | siege_tank, hellion, cyclone, liberator, banshee, medivac, raven, widow_mine(静) |
| **pulse 能量体** | `clip_pulse_float` | 整体脉冲缩放 | archon |
| **stilt 高跷** | `clip_stilt` | 极慢大步+顶部滞后摆 | colossus |
| **巨型舰** | `clip_hover`(低速) | 微浮+微摆 | battlecruiser, carrier, mothership, warp_prism |

## 4. 建筑与特殊处理

- **建筑 24 栋**：不移动，只做 `_idle`（呼吸浮沉 bob 0.008 / 微摆 sway 0.012，48 帧）；
  水晶塔/枢纽带能量脉冲（pulse 0.02/0.015），孵化场/坑道虫呼吸加重（bob 0.012-0.014）；
- **widow_mine**：埋地单位无 move，只留极微 idle（bob 0.004）；
- **blade/tendril/wing/barrel 附属摆动**：工厂参数化（arm_swing/tendril/flap/barrel_sway），反相成对。

## 5. 技术规范

- **管线**（沿用过度烹饪验证过的模式）：REST 相对关键帧 → 每对象独立 action（`<clip>@<ob>`）→
  NLA 同名轨道合并 → `export_animation_mode='NLA_TRACKS'` 导出 GLB → 引擎按片段名播放。
- **命名**：`<key>_idle` / `<key>_move`（如 `marine_move`、`overlord_idle`），引擎动画名即片段名。
- **根节点**：每个资产一个 key 命名 Empty（与静态 GLB 同名同规），世界位移由引擎驱动根节点。
- **脚本**：`scripts/anim_lib.py`（工厂库）+ `scripts/build_animations.py`（烘焙/导出/检验图）。

## 6. 验收标准

1. GLB 动画数与命名全对齐：**133/133 ✓**（json 解析零缺失零多余）；
2. 循环无缝：整数倍 TAU + 首尾帧相等（工厂强制）✓；
3. 逐帧检验图运动原型可读：先导 12/12 ✓，全量三族 sheet ✓；
4. judge 抽验：朝向/部件连接/squash 幅度（待抽验）。
