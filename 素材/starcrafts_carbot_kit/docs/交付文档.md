## 2. 快速接入

- **GLB**（4.0MB，795 节点）：拖入引擎。顶层结构 = 79 个以 key 命名的 Empty 组（各部件为其子节点）+ 9 块地台板（`plate_{u,h,b}{terran,zerg,protoss}`，展示场景用，可删）。按组整体挂接/隐藏/实例化。
- **PNG**：`sheets/singles/<key>.png` 512×512 透明，居中构图，适合 sprite/billboard/头像。
- **blend**：`StarCrafts` 集合=九板方阵（每族 单位/英雄/建筑 三板），`StarCraftsSingle` 集合=原点朝 +Y 单件 rig（默认 hide_render）。

## 2.5 动画（v6.3）

`starcrafts_animated.glb`：**206 段**动画（24fps，原地跑步机式，世界位移由引擎驱动根节点）。
单位/英雄三段式 `<key>_idle`/`<key>_move`/`<key>_attack`；星灵 12 战斗单位另有进攻链
`<key>_aim`（就位过渡 one-shot）与 `<key>_cast`（终结技 one-shot），引擎状态机：
move → aim(1次) → attack(循环) → cast(冷却好时插播) → 回 attack。

| 片段 | 数量 | 内容 |
|---|---|---|
| `<key>_idle` | 79 | 呼吸浮沉+眨眼（建筑=微摆/脉冲，无眨眼的自动跳过） |
| `<key>_move` | 54 | 9 类运动原型：biped 碎步/摇摆/行军、quad 轻跳/重踏、roll 滚、crawl 爬、hover 悬浮、fly 飞、tank 颠簸、pulse 能量体、stilt 高跷 |

Godot 接入：`AnimationPlayer` 里按 `<key>_idle` / `<key>_move` 播放并设循环；移动时切 move，
移动向量交给根节点（GLB 根=资产 key）。设计规范与每单位参数见源工作区 `starcrafts/docs/动画设计.md`。

## 3. 尺寸参考

单位脚底 z=0，步兵高 1.0-1.6，大型单位（thor/ultralisk）1.5-1.7；建筑 1.0-1.7 高、底面 1.0-2.6；悬浮单位自带悬停高度（overlord 2.05、carrier 2.30、mothership 2.35、archon 1.30、observer 2.00）。格子换算可自定（建议 1 格 = 1.0）。

## 4. 复现命令（源工作区 `e:\godot\blender\starcrafts\`）

```bash
BLENDER="E:/app/steam/steamapps/common/Blender/blender.exe"   # 5.2.2 LTS

$BLENDER -b -P scripts/build_all.py              # 全量构建 + 场景双视角图（~1.5 分钟）
$BLENDER -b -P scripts/build_all.py -- noview    # 只构建不渲图
$BLENDER -b models/starcrafts.blend -P scripts/render_singles.py                          # 全部单件（~12 分钟）
$BLENDER -b models/starcrafts.blend -P scripts/build_animations.py                        # 全量动画 GLB（133 片段）
$BLENDER -b models/starcrafts.blend -P scripts/build_animations.py -- --frames            # +逐帧检验图
$BLENDER -b models/starcrafts.blend -P scripts/render_singles.py -- only=marine,zergling  # 指定资产
python scripts/make_catalog.py                   # 重拼目录图
python scripts/gen_manifest.py                   # 重生成资产清单
```

采集/调研脚本（需 cn.bing.com 可达）：`collect_refs.py` / `collect_buildings.py` / `collect_heroes.py` → `clean_refs.py`（清洗+拼版）→ `emit_research.py`（散列档案）。

## 5. 脚本结构（扩展新资产）

- `carbot_kit.py`：风格基元库（sphere/capsule/rbox/bent_cone/torus + sRGB hex 材质 + emit/alpha），零第三方依赖，可独立复用。
- builder 约定：面向 +Y、脚底 z=0、几何全圆润；`BUILDERS` dict 键=资产 key；英雄按族分 `BUILDERS_T/Z/P`。
- 新增流程：`research/UNIT_LORE*.py` 加调研条目 → builder 函数 → `build_all.py` 的 ORDER_KEYS 注册 → 重跑 → `render_singles.py` → `make_catalog.py`。

## 6. 踩坑备忘（改脚本前必读）

1. 五官 y 位移必须推到身体表面之外（y < 半径会整颗埋进身体）。
2. cone 的 r1=底 r2=顶，尖刺一律 r1 宽 r2 尖；`"%d" % 浮点` 命名会把 ±0.55 都截成 '-0'，循环命名用 enumerate。
3. bent_cone 不要做细飘带/镜像件（易碎裂）——改弧线递减球串，根部球放大埋进宿主。
4. 循环建集合时公共对象（地台）必须显式 `K.set_coll(root)`，否则混进上一个资产的 rig。
5. GLB 导出：每资产建 key 命名 Empty 并 parent（parent 前存 matrix_world 再恢复）；只 select 场景集合导出，排除单件 rig。
6. 露脸角色的眼睛 y 要推到脸球前缘外（脸 scale y 0.6 时前缘=中心y+0.6r）。
7. 渲染踩坑合集见源工作区（相机 to_track_quat 方向、EEVEE 无头失效、OptiX 降级 CPU、单件循环必设 scene.camera 等）。
