# 测试清单：法术装备 + 图鉴（2026-10-24）

代码已推送（a088dae）。启动游戏（摄像头模式），按下面顺序过一遍。

## 1. 法术配置面板（C 键 / 左上角"法术配置"按钮）

- [ ] C 打开：游戏暂停、战场敌人冻结；C/ESC 关闭：恢复
- [ ] 取消一个法术 → 底部法术栏对应槽变暗标"未装备"
- [ ] 取消后试三种施法，都应提示"未装备该法术"且不扣蓝：
  - 画它的符文
  - 拳→张掌（掌心火弹）
  - 按它的数字键
- [ ] 勾满 5 个后再勾第 6 个：拒绝 + 提示（先把 5 个勾满再取消一个、勾两个新的）
- [ ] 关闭游戏重开：勾选状态还在（存档 user://spell_loadout.json）

## 2. 图鉴（H 键 / Tab）

- [ ] ←/→ 或点底部标签：符文页 ↔ 手势骨架页切换
- [ ] 骨架页 6 个手势可认：捏合/握拳/张掌 + 比耶/点赞/我爱你（灰卡"未启用"）
- [ ] 有未装备法术时，符文页对应卡片有"未装备"角标

## 3. 正常玩法回归

- [ ] 全部装备状态下，画符/掌心火弹/数字键与以前一样正常

## 4. 扩展手势（默认关，想测再开）

打开方式：`scripts/gesture_fsm.gd` 顶部 `static var extended_gestures = true`，重启游戏。
**先清冰霜录制样本**（图鉴/录制面板里把冰霜的录制笔数清空），旧三角样本会污染识别。

- [ ] 比耶/点赞/我爱你：HUD 姿势显示（F1）能认出三个新手形
- [ ] 画 S 波（横向波浪 ~1.5 个周期）→ 放冰霜领域；画旧三角 → 也放冰霜（平滑降级）
- [ ] Z 字仍是链电，不被 S 波抢走
