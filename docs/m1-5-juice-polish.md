# M1.5 实施文档：演出打磨

> 前置：M1.4 完成。产出：打击感与画面表现到位，"能玩"变"好玩好看"。

## 目标

补齐视觉反馈层：受击/死亡/枪口/法术特效强化、相机手感、环境氛围。纯表现层，不改玩法逻辑。

## 任务分解

### 1. 敌人反馈
- [ ] **受击闪白**：材质 `emission` 瞬时拉白 0.08s（遍历 MeshInstance3D 设 `transient emission_energy`，或 overlay 半透明白壳 mesh 缩放 1.02）
- [ ] **受击顿帧**：重击（火球/风刃）命中 0.05s 微顿（`Engine.time_scale` 0.2→1，谨慎复用）
- [ ] **死亡演出升级**：炸飞 + CPUParticles3D（队色碎片 20 粒 + 星星转圈 3 颗 CarBot 风）+ 地面残留焦痕（Decal 或贴地黑圆渐隐 5s）
- [ ] **冰冻外观**：整体材质偏蓝白 + 顶部冰晶小 mesh；解冻渐变恢复
- [ ] **击退**：风刃命中后倾 → 恢复姿态（tween 旋转 X 轴 15°→0）

### 2. 枪口与子弹
- [ ] 枪口火光：开枪瞬间 muzzle 处 CPUParticles3D 3 粒橙黄 + OmniLight 闪 0.05s
- [ ] 曳光强化：子弹改锥形拉伸 + 拖尾（TrailRenderer 思路 3D 版：短渐隐圆柱）；掠屏弹加 whoosh 假音效占位（可选）
- [ ] 掠夺者炮弹：橙色球 + 命中地面小爆（未命中玩家也炸地）

### 3. 法术特效强化
- [ ] 火球：飞行拖尾粒子 + 爆炸双层（白核快闪 0.15s + 橙焰球扩散 0.4s + 冲击波环贴地扩散）+ 相机微震（按距离衰减）
- [ ] 链电：主干白蓝 + 分支细电叉随机 2-3 条 + 命中点闪光球；0.25s 消失（比 M1.2 精细）
- [ ] 冰域：冰环从落点扩散（r0→6）+ 地面霜纹（半透明圈叠 2 层）+ 空中冰晶缓落粒子；冻结敌人头顶小雪花
- [ ] 风刃：弧面网格改双层（外青内白）+ 沿途尘土粒子；击退敌人短暂僵直演出
- [ ] 施法瞬间：掌心/鼠标位法阵闪光（2D 层画符拖尾已有，加爆闪）

### 4. 相机与环境
- [ ] 呼吸微摆：相机 sin 摆动 ±0.15°/1.2s 周期；受击震屏改 Trauma 模型（trauma² 混合 Perlin 噪声，衰减 0.8s）
- [ ] 天空/雾：轻雾 `Environment.fog_light_color` 草地色、`fog_density=0.008` 拉纵深层次
- [ ] 布景加密：两侧树/岩/矿场补 15-20 件（固定种子）；远处地平线放 2-3 大件剪影（加大号 e_tree）
- [ ] 光照微调：黄昏暖色调可选方案（平行光色温 0.9 橙）——做两套常量，目检选一套

### 5. 音效占位（可选，时间富余才做）
- [ ] 用 AudioStreamGenerator 生成白噪/方波占位音：射击嗒/爆炸轰/施法嗡/受击闷——仅占位分辨事件，正式音效后补

## 验收标准
1. 枪兵齐射时：枪口火光+曳光弹道清晰可读，不晃眼（粒子量克制）
2. 火球炸一群：闪-焰-环三层爆炸+相机随距离震动；敌人炸飞+星星+焦痕全套演出
3. 冰/电/风各自一眼可辨（蓝冻/白电/青风），冻结敌人外观明显
4. 帧率：Forward+ 下 1080p ≥60fps（20 敌+全特效同屏，Task Manager 或 Godot profiler 抽查）
5. 截图全量过一遍 visual-judge（构图/特效可读性/穿模检查）

## 风险与回退
- **粒子过量掉帧**：CPUParticles3D 数量减半→改 GPU 粒子（Forward+ 支持）→砍层（保核心闪白/爆炸）
- **材质 emissive 遍历改闪白性能差**：改为整敌人 overlay 壳 mesh 方案（一次构建）
- **泛光过曝**：Environment glow 强度/阈值回调，HDR=off 兜底
