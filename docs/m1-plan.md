# M1 主计划：第一人称手势施法战场（3D）

> 2026-10-05 定稿。素材：`素材/starcrafts_carbot_kit` v6.3+（CarBot 星际 3D 资产包）。
> 本文档是 M1 阶段的总纲；各里程碑的实施细节见 `m1-0` ~ `m1-6` 分文档。

## 1. 游戏形态

真 3D、FPS 视角（Godot 4.6，Forward+ 渲染器）：

- 玩家站在**人族阵地**（指挥中心 + 地堡 + 导弹塔）前方的固定位置，视线望向战场纵深
- **枪兵 / 掠夺者从左右两侧和远处**向玩家走来，进入射程后停下开枪，曳光弹朝相机飞
- 玩家用**手势画符施法**消灭敌人；鼠标全程兜底（移动=瞄准，按住画符=施法）
- 摄像头**只用于手势追踪**，不做画面背景（AR 摄像头背景模式留作日后可选）
- 相机固定站位 + 呼吸感微摆 + 受击震屏；不做鼠标转视角（鼠标留给手势兜底）

## 2. 手势操作

| 操作 | 效果 | 法力 |
|---|---|---|
| 握拳 → 画◯ → 张掌 | 火球术：投射物飞向瞄准点，AoE 爆炸 | 25 |
| 握拳 → 画Z → 张掌 | 链电术：闪电链最近 3 敌 | 20 |
| 握拳 → 画△ → 张掌 | 冰霜领域：地面冰环，冻结+减速 | 30 |
| 握拳 → 画╱ → 张掌 | 风刃：正面扇形横扫+击退 | 15 |
| 握拳 → 直接张掌 | 掌心火弹：自动打最近敌人 | 8 |
| **空闲持续张掌** | **魔法护盾**：格挡正面子弹，持续耗蓝 | ~10/s |

手势管线（追踪/姿势分类/FSM/$1 识别）与渲染完全解耦，M0 代码原样复用。

## 3. 数值初版（M1.6 统一调）

### 玩家
- HP 100，护盾格挡正面 ±60° 内子弹

### 敌人
| 单位 | HP | 速度 | 停距 | 攻击 | 间隔 |
|---|---|---|---|---|---|
| 枪兵 | 30 | 1.6 m/s | 10 m | 3 连发×4 伤，命中~70%（失准弹擦屏） | 1.8s |
| 掠夺者 | 100 | 1.1 m/s | 14 m | 单发 12 伤，弹大速慢 | 2.6s |

- 逼近 3m 内 → 近战猛击（15 伤，1.2s/次），玩家不能无视近身
- 死亡：炸飞旋转+压扁+粒子爆散（代码演出，素材无死亡动画）

### 法术
| 法术 | 伤害 | 范围 | 备注 |
|---|---|---|---|
| 火球 | 40 | AoE r2.5m | 投射物命中/落地爆 |
| 链电 | 25×3 | 链条 | 从瞄准点向最近 3 敌跳 |
| 冰域 | 10 | r6m | 冻结 3s（掠夺者 2s） |
| 风刃 | 18 | 正面扇形 r8m | 击退 3m+打断射击 |
| 掌心火弹 | 8 | 单体 | 自动瞄准 |

### 波次
- 第 N 波：3+2N 个枪兵，左右交替入场；第 3 波起每波混 ⌈(N-2)/2⌉ 个掠夺者
- 波间 5s（回蓝+喘息），无尽模式，记分+最高纪录（枪兵 10 分/掠夺者 30 分）

## 4. 架构决策记录（ADR）

1. **单件 GLB 自带动画**（已验证）：`models/单件GLB/marine.glb` 内含 marine_idle/move/attack 三段动画。每敌人直接 `load()` 自己的小 GLB 实例化即可独立播动画，无需从动画总包拷贝片段。~~原"动画拷贝/子树实例化"风险方案作废~~
2. **渲染器 Forward+**：桌面目标，泛光/光照让魔法特效出彩。GL Compatibility 可随时切回，代码不依赖 Forward+ 独有特性
3. **敌人 = Node3D + GLB 子节点**，逻辑状态机驱动 AnimationPlayer；命中判定用**世界空间手动球体检测**（不挂物理体，够用且省事；敌人数量 ≤ 30）
4. **手势层不动**：`hand_tracker / pose_classifier / gesture_fsm / dollar_recognizer / one_euro_filter` 保持 M0 状态；2D 骨架/拖尾/HUD 挂 CanvasLayer 叠在 3D 视口上
5. **旧 2D 模式保留**：`--ward`（守卫法阵）、`--practice`（练习靶）参数进入，老测试套件保绿；默认模式 = 3D 战场
6. **法术层新建 `spell_caster_3d.gd`**，不复用 2D `spell_manager.gd`（空间语义完全不同，强改不如并行；旧文件留给旧模式）
7. **素材防重导入**：`素材/` 目录放 `.gdignore`；实际用的 GLB 拷到 `res://assets3d/`

## 7. 验证方式

- 每个里程碑：Godot headless 跑测试 + 带窗口截图目检（无摄像头走鼠标兜底）
- 全量回归：`--smoke-test`(14) `--e2e-test`(35) `--robust-test` `--game-test`(9) + 新 `--battle3d-test`
- 动画/画面质量：截图抽验（关键帧肉眼 + 必要时 visual-judge）
