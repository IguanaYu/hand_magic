## 任务分解

### 1. `tests/battle3d_test.gd`（新建，`--battle3d-test` 触发，headless）
> 模式：构建战场 → 快进模拟 → 断言落盘 `tests/battle3d_result.txt`。参考 M0 game_test 的注入式写法（直接调方法/快进 timer），不依赖摄像头与渲染。

- [ ] **场景构建**：battlefield ready 无报错，相机/灯光/地面/城堡节点存在
- [ ] **敌人生成与状态机**：spawn marine → ADVANCE；快进位移 → 进停距 → HALT/FIRE；frozen 后攻速受制
- [ ] **伤害系统**：take_damage(999) → died 信号 → 场上移除+记分
- [ ] **法术判定**（注入 screen_pos 打固定目标）：火球 AoE 范围内外各放一敌，伤害只中范围内；链电恰好 3 目标；冰域冻结时长；风刃击退距离
- [ ] **玩家生存**：player_hit 扣血→红闪状态位置→HP=0 触发 GAME_OVER
- [ ] **波次**：WaveTable.wave(1/3/5) 数值断言；全灭→INTERMISSION→SPAWNING；restart 全清
- [ ] **护盾**：子弹进盾锥被销毁、法力扣减、空蓝破盾
- [ ] 目标 ≥20 项断言，全 PASS
